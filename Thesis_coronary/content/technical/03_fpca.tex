\section{Functional Principal Component Analysis}
\label{sec:tech-fpca}

Functional principal component analysis (FPCA) is a dimension reduction method designed for functional data, where each observation is a whole function, referred to as a curve.
A curve is recorded at many positions whose neighbouring values are strongly correlated, so entering the values one by one would give a regression model many covariates that largely repeat each other.
FPCA extends principal component analysis from vectors to functions and describes the curves by the few shapes along which they differ most, referred to as components.
How strongly a curve shows each component is given by its scores, which are uncorrelated and can replace the values of the curve as covariates \cite{wang2016fda}.

\label{sec:tech-fpca-components}%
The curves are compared along a domain common to all of them, with the position $t$ running from the start ($t = 0$) to the end ($t = 1$).
Curve $i$ of the $N$ curves is written $x_i(t)$, and the average of the curves at each position is the mean function $\mu(t)$.
FPCA describes how the curves deviate from this mean, so the mean is first subtracted at each position, and what is left shows where and by how much a curve lies above or below the average.

Neighbouring positions tend to rise and fall together across curves, and so can positions far apart, for example when a curve lies above the mean along its whole length.
How the deviations at two positions $t$ and $u$ vary together is described by the covariance function $\Gamma(t, u)$.
FPCA breaks this function down into shapes $\phi_k(t)$, each of which satisfies
\begin{equation}
  \int_0^1 \Gamma(t, u)\, \phi_k(u)\, \mathrm{d}u = \lambda_k\, \phi_k(t),
  \label{eq:tech-fpca-eigen}
\end{equation}
where $\phi_k$ is the $k$th eigenfunction of the covariance and $\lambda_k$ is its eigenvalue \cite{wang2016fda}.
The covariance applied to an eigenfunction returns the same shape multiplied by $\lambda_k$, which is the variance of the curves along that shape.
The eigenfunctions are orthogonal, so no two of them describe the same pattern, and each is scaled to unit size, which leaves the amount of a pattern to the scores \cite{wang2016fda}.
They are ordered by their eigenvalues, $\lambda_1 \ge \lambda_2 \ge \dots \ge 0$.
The first eigenfunction is the shape along which the curves vary most, and once it is subtracted from the curves, the second is the shape along which the rest varies most (Figure~\ref{fig:tech-fpca-steps}).

The score of curve $i$ on component $k$ measures how much of the shape $\phi_k$ the curve contains,
\begin{equation}
  \xi_{ik} = \int_0^1 \left\{ x_i(t) - \mu(t) \right\} \phi_k(t)\, \mathrm{d}t .
  \label{eq:tech-fpca-score}
\end{equation}
A large positive score means that the curve deviates from the mean much like the shape, and a large negative score that it deviates the opposite way.
Across the curves, the scores on component $k$ have variance $\lambda_k$ \cite{wang2016fda}.
Each curve can then be rebuilt from the mean and the first $K$ shapes, each weighted by the curve's score,
\begin{equation}
  x_i(t) \approx \mu(t) + \sum_{k=1}^{K} \xi_{ik}\, \phi_k(t),
  \label{eq:tech-fpca-kl}
\end{equation}
which is the Karhunen--Lo\`eve expansion truncated after $K$ components.
For a given $K$, no other set of $K$ shapes describes the curves more closely on average \cite{wang2016fda}.

To show how much the curves vary along a shape, a component is drawn as the mean together with its mode of variation,
\begin{equation}
  \mu(t) \pm \alpha \sqrt{\lambda_k}\, \phi_k(t),
  \label{eq:tech-fpca-mode}
\end{equation}
where $\alpha$ usually ranges up to 2 \cite{wang2016fda}.
The two curves show what a high and a low score look like, and which parts of the curve the component changes most (Figure~\ref{fig:tech-fpca-modes}).
A component may, for example, describe an overall shift in level or a contrast between the start and the end of the curve.
The name given to a component is a reading of this plot, not a tested property of the curves.
The sign of a shape is arbitrary, as flipping it together with every score describes the same curves, so a sign convention is fixed before components estimated on different samples are compared.

\label{sec:tech-fpca-k}%
The share of the total variance that the first $K$ components explain is referred to as the fraction of variance explained (FVE) (Figure~\ref{fig:tech-fpca-modes}, right).
Keeping more components describes the curves more closely, but every added component has to be estimated and adds its own error.
A threshold on the FVE can set this balance, although the threshold itself is an ad hoc choice \cite{wang2016fda}.
A less arbitrary guide is how stable the components are when the sample changes \cite{song2018stability}.
FPCA is then repeated on many samples drawn at random from the curves, and the first $K$ shapes are compared between the samples.
Shapes that describe a pattern shared by the curves return in every sample, whereas shapes that mostly describe noise change from one sample to the next.

\label{sec:tech-fpca-domain}%
In practice, each curve is recorded as values on a grid of positions shared by all curves.
The covariance function then becomes a matrix, and Eq.~\eqref{eq:tech-fpca-eigen} reduces to the eigendecomposition of this matrix \cite{wang2016fda}, which is a principal component analysis with the grid positions as variables.
The comparison position by position assumes that a position means the same on every curve.
When a feature such as a peak lies at different positions on different curves, the mean flattens it and no longer resembles any of the curves, and differences in position cannot be separated from differences in size \cite{wang2016fda}.
How the curves are aligned before FPCA therefore determines what a component can describe.
Landmarks that can be identified on every curve fix the positions they mark \cite{wang2016fda}, while a feature between two landmarks can still lie at different positions.
