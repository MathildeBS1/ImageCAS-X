\chapter{Clinical Background}
\label{ch:clinical}

This chapter establishes what the coronary arteries are, how they vary between people, how
computed tomography records them, and why the shape of the arterial tree carries clinical
meaning.
Section~\ref{sec:anatomy} covers the heart as a pump, the coronary arterial tree that supplies
it, and coronary dominance.
Section~\ref{sec:variants} describes the anatomical variants that change the connectivity of
that tree.
Sections~\ref{sec:cad} and~\ref{sec:ccta} cover coronary artery disease and the imaging
modality used to observe it.
Section~\ref{sec:geometry} sets out the mechanism by which the geometry of the tree becomes a
clinical quantity.

Where a quantity in this chapter has also been measured in the ImageCAS-X cohort
\cite{bransby2026imagecasx}, both values are given.
Cohort figures were computed over its 800 usable cases from the released centerline labels and
descriptor table by \texttt{scripts/cohort\_numbers.py}, which writes every number quoted here to
a JSON file tagged with the version of the code that produced it.
