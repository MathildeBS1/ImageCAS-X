\section{Network architecture}
\label{sec:pipeline-architecture}

CAS-Net \cite{dong2023casnet} is a 3D \textbf{U-Net} \cite{ronneberger2015unet}. In a U-Net, an \textbf{encoder} repeatedly shrinks spatial
resolution while growing feature depth, so deeper layers see more context. The input holds one
grayscale intensity channel per voxel (the CT scan); each channel added going deeper is a
separately learned pattern detector. A \textbf{decoder}
mirrors this back up to full resolution. \textbf{Skip connections} carry the encoder's fine
spatial detail directly across to the matching decoder level, so the output is both contextually
informed and spatially precise.

A coronary artery is thin, branching and of varying caliber, and this anatomy strains a plain
U-Net's fixed-size convolutions and unconditional skip connections. CAS-Net keeps a standard U-Net
backbone at five levels -- a $128\times160\times160$ input patch is halved by four max-pooling
steps down to an $8\times10\times10$ \textbf{bottleneck}, while
channel count grows $16\to32\to64\to128\to256$ -- and adds three attention modules on top of it,
each addressing a specific way coronary anatomy challenges that backbone. Each level's convolution
block is a \textbf{residual} double convolution (\texttt{ResEncoder3d}): two $3\times3\times3$
convolutions (batch norm, which normalizes each channel's activations to the batch's own mean and variance; then
ReLU, which zeroes negative activations). Stacking two small kernels widens the effective
receptive field and adds a nonlinearity between them, at far fewer parameters than one larger
kernel. A $1\times1\times1$ convolution shortcut is added back before the
final ReLU, easing gradient flow through the five downsampling steps -- the first of two
departures from a plain U-Net; a plain U-Net's double-conv block has no such shortcut.
Figure~\ref{fig:pipeline-casnet} shows the full architecture; the second departure is the three
added attention modules:
\textbf{SAFE} at the bottleneck, \textbf{AGFF} at every skip connection, and \textbf{MSFA} at the
output, each detailed below in that order.

Coronary vessels vary enormously in width, and two voxels of the same vessel can sit on
opposite sides of a background gap (a bifurcation, a segment obscured by calcification) that local
convolutions alone struggle to bridge. \textbf{SAFE} fixes both at the bottleneck (Figure~\ref{fig:kernel-spacing}):
the same kernel is run four times, each time with its individual weighted positions spread a
different distance apart, so each pass covers more ground per weight and the four passes together
widen the receptive field to match vessels of every width; then a residual self-attention step lets
any two voxels influence each other directly, however far apart:er far
apart:
\[
  A = \mathrm{softmax}\!\left(\frac{Q^{\top}K}{\sqrt{C}}\right) \in \mathbb{R}^{N\times N}.
\]

A skip connection's fine detail is not unconditionally trustworthy: at the shallowest encoder
levels, only one or two convolutions removed from the raw intensities, the network has not yet
resolved which voxels are vessel, so that detail is easily confused with noise -- yet pooling
discards it permanently, so it cannot simply be dropped either. \textbf{AGFF} sits at every skip
connection and weighs two things against each other: the encoder's raw detail from the same
level, and the decoder's already-processed signal, which comes from one level deeper and is
upsampled up to meet it. This weighting is learned per channel and per input, not fixed by depth:
AGFF computes a per-channel attention weight from the two features combined, then uses it to scale
down unreliable encoder channels before adding them, unweighted, to the decoder feature -- instead
of concatenating both unconditionally, as a plain U-Net's skip connection does:
\[
  \mathrm{AGFF}(\mathrm{low}, \mathrm{high}) = a \odot \mathrm{low} + \mathrm{high}_{\downarrow},
  \qquad a \in [0,1]^{C_{\mathrm{low}}}.
\]

A vessel segmented from the decoder's finest resolution alone can fragment into disconnected
pieces: each voxel there has a narrow receptive field, precise about location but easily broken by
a few misclassified voxels along a thin vessel's path. A lower-resolution level's voxels each
cover more ground, so they more reliably signal that a vessel is connected, even if less precise
about exactly where. \textbf{MSFA} fixes this by fusing all four decoder resolutions coarse to
fine: at each step the running aggregate is upsampled, gated against the next, more detailed
level, and added back, so a lower-resolution but better-connected prediction fills in wherever
that level's own detail is not confidently gated on:
\[
  \mathrm{agg}_i = g_i \odot c_i + \mathrm{agg}_{i-1}{\uparrow},
  \qquad g_i = \sigma\big(\mathrm{conv}([c_i,\ \mathrm{agg}_{i-1}{\uparrow}])\big).
\]
A final $3\times3\times3$ convolution turns the fully-fused map into the two output channels, a
volume of raw numbers, one for background and one for lumen. The network itself never makes a
final yes-or-no call on any voxel; that decision happens afterward.
