I have added the below learning objectives that should only be taken as a rough guide:

 

Describe the function of the heart with a special focus on the role of coronary arteries
Describe how computed tomography is used to record and visualize the coronary arteries
Describe the common topology of the coronary arteries and their variants
Describe the state-of-the-art of segmentation of coronary arteries and topological descriptions of the coronary arteries
Implement, validate and document a state-of-the-art segmentation framework for coronary arteries from computed tomography
Develop, implement, revise and validate methods for topological characterization of coronary artery trees.
Extract topological features like branching patterns, dominance, angles, and tortuosity.
Use the framework on a large cohort and do population descriptions and statistics.
Implement and test outlier detection and extreme value detections of topological features
Associate topological features with patient outcomes.
